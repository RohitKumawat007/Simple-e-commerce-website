## Features ✨

- 📱 Browse products with images & prices
- 🛒 Add/remove items to cart
- 💰 Live cart total & quantity updates
- ✅ Checkout with order confirmation [web:1][web:8]

## Tech Stack 🛠️

- HTML5, CSS3, JavaScript (ES6+)
- LocalStorage for cart persistence [web:3]
